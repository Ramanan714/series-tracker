# Series Tracker - Telegram Web App

A comprehensive tracking application for series, anime, movies, books, manga, manhwa, and more. Designed to work as a Telegram Web App with full offline capabilities.

## Features

- 📊 **Dashboard** - View all your tracked items categorized
- ➕ **Add Items** - Add new series with progress, ratings, and notes
- 🗑️ **Remove Items** - Easily remove items from any category
- ⭐ **Favorites** - Mark and manage your favorite items
- 📝 **Wishlist** - Plan what to watch/read next
- 👤 **Profile** - View statistics and manage data (export/import)
- 🌓 **Dark/Light Theme** - Automatic theme detection with manual toggle
- 💾 **Local Storage** - All data saved locally in your browser
- 🔗 **Telegram Integration** - Seamless integration with Telegram Web App

## Categories

- Watching
- Completed
- Plan to Watch
- On Hold
- Dropped
- Favorites (Special)
- Wishlist (Special)

## Installation

### For Telegram Bot Setup:

1. Create a new bot with [@BotFather](https://t.me/botfather) on Telegram
2. Get your bot token
3. Host these files on GitHub Pages or any static hosting service
4. Set up your bot's web app URL using BotFather:
   - Send `/setdomain` to BotFather
   - Select your bot
   - Enter your GitHub Pages URL

### For Local Development:

1. Clone or download this repository
2. Open `index.html` in your browser
3. All data is stored locally in your browser's localStorage
